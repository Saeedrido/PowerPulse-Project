About the project

What is PowerPulse?

PowerPulse lets anyone remotely know whether electricity is currently available at a registered location — a home, a pharmacy, a shop, or a clinic. A small IoT device detects power changes and reports them to the backend, which stores every ON/OFF event and shows the live status on a web dashboard.

Utility power is unpredictable, and by the time you find out your shop has been without power, stock may already be spoiled. PowerPulse turns the unknown into a constant you can watch — wherever you are.

FAQ

Questions,
answered

Can't find what you're looking for? Reach us at hello@powerpulse.app — we reply fast.

Do I need any hardware to try it?
+
No. The built-in IoT simulator sends real power events through the exact same API a physical device would use, so you can experience the full flow — status, alerts, and history — with zero hardware.
How does the IoT device report power?
+
Each device has a unique code. It calls POST /devices/status with ON or OFF, and the backend validates the code, logs the event, updates the live status, and fires an alert when the state actually changes.
Can I monitor more than one location?
+
Yes. Add unlimited locations on the Starter plan to explore — home, pharmacy, shop, and clinic all live on one dashboard. Paid plans scale the number of devices and add team features.
When will SMS and WhatsApp alerts be available?
+
The notification system is already separated from the core power logic, so new channels plug in without touching the event code. Email and WhatsApp are next on the roadmap, with SMS and Telegram to follow.
Is my data secure?
+
Passwords are hashed with bcrypt, sessions use signed JSON Web Tokens, and every user only ever sees their own locations and events. The API validates all input server-side.
Can I export my event history?
+
CSV export is on the roadmap. Today, the API returns the full event timeline for any location, and the history view is filterable per location.
